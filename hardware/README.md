# Carcasa e impresión 3D / Enclosure and 3D printing

La carcasa está diseñada para alojar una batería principal LiPo de **3.7 V, formato 523450**. / The enclosure is designed to accommodate a **523450** format **3.7 V** main LiPo battery.

## Impresión / Printing

### Bambu Lab A1 · PETG · 0.4 mm

[Proyecto Bambu Studio / Bambu Studio project](bambu/Huskey_Pocket_A1_PETG_04.3mf)

Incluye las cuatro piezas orientadas en una sola cama, ajustes de impresión y soportes. Preparado para una placa PEI texturizada. / Includes all four parts oriented on one plate, print settings and supports. Prepared for a textured PEI plate.

[Configuración e instrucciones / Settings and instructions](bambu/README.md)

### Archivos STL / STL files

Abre los archivos STL en tu laminador para preparar la impresión 3D. Usa `CASE.blend` en Blender para editar el diseño de la carcasa.

Open the STL files in your slicer to prepare them for 3D printing. Use `CASE.blend` in Blender to edit the enclosure design.
